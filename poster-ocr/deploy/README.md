# Развёртывание переехало

Всё, что про запуск и развёртывание — системы и сайта вместе или по
отдельности, в Docker и без него, — теперь в [`../../deploy/`](../../deploy/README.md).

Файлы здесь — переадресация для уже установленных серверов (служба systemd,
сторож в cron, задачи планировщика Windows ссылаются на старые пути):
`poster.sh`, `install.sh`, `poster.ps1` вызывают одноимённые скрипты из
`deploy/crm/`.

# Сайт-визитка

React 19 + Vite + TypeScript, обычные адреса через React Router (`/uslugi`,
`/kontakty`) — сайту важно индексироваться, поэтому не «после решётки», как
в системе. Пока это каркас: шапка, три страницы, подвал и ссылка «Вход для
сотрудников» на `/poster-crm/`.

## Разработка

```bash
npm install
npm run dev          # http://localhost:5174
npm run check        # проверка типов
npm run build        # сборка в dist/ (в репозиторий не идёт)
```

Порт 5174, а не 5173: у интерфейса системы (`../poster-ocr/web`) уже 5173,
оба dev-сервера могут работать одновременно. Ссылка «Вход для сотрудников» в
разработке проксируется на локальную систему (`vite.config.ts`), поэтому
для неё нужен запущенный uvicorn на 8000.

## Как сайт попадает на сервер

`Dockerfile`: Node собирает `dist/`, итоговый образ — маленький Caddy, который
отдаёт эти файлы и на любой адрес без файла возвращает `index.html`
(`Caddyfile` рядом). Главный Caddy сервера (`../deploy/Caddyfile`) проксирует
на него корень домена; система живёт под `/poster-crm/` и с сайтом не
пересекается. Обновить сайт на сервере:

```bash
cd /opt/poster && git pull && docker compose up -d --build site
```

## Структура

    index.html          точка входа Vite, мета-теги
    public/             файлы как есть (favicon)
    src/main.tsx        монтирование, BrowserRouter
    src/App.tsx         шапка, маршруты, страницы
    src/styles.css      стили; тема своя, с системой не связана
